

## Getting Started

Follow these instructions to set up and run the project locally.

### Prerequisites

Make sure you have the following installed on your system:

- Node.js 
- npm (comes with Node.js)

### Installation

1. **Navigate to the project directory**  
   Open a terminal (Bash) and navigate to the path of the project
   cd src/Server/mongodb

2. **Start the backend server by running:**
   node index.js

3. **Open a PowerShell terminal and run the following command:**
   npm install react-scripts

4. **Run the following command to clean the npm cache**
   npm cache clean --force

5. **Use the following command to start the development server:**
   npm start

6. **Add .env file**  
   Create a .env file in the root directory of the project and add the required environment variables.
